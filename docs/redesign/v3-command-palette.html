Added an idempotency middleware that stores the first response for each Idempotency-Key for 24 hours and replays it on retry. It is mounted only on the create route in orders.ts:

router.post("/orders", requireAuth,
  idempotency({ ttlSeconds: 86_400 }), createOrder);
