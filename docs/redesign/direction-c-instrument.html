  • Retry with the same key: 200 with the stored order and Idempotent-Replay: true.
  • Missing or malformed key: 400 with a zod error.

Direction C · Instrument

Idea. Codevo reads like a precision instrument: cool slate surfaces, graphite type, one electric signal colour. Everything that's alive (running agents, timers, the primary action) glows in acid lime. Everything that's settled goes neutral. Metadata and section headers use SF Mono uppercase labels. Numbers are always tabular, so live readouts don't jitter.

Why acid lime, not signal cyan. On blue-grey slate, cyan sits too close to the surface hue and reads as "a bit more blue", so it stops meaning "live". Lime is almost the complement of slate, so a 7px dot is enough to be seen in peripheral vision. It also stays clear of the semantic colours: amber means blocked, coral means failed, and teal-mint marks diff additions. Because lime only ever means "live" or "go", it keeps its signal value. In light theme it drops to a deep moss (#4A7500) for AA text, and dots use a brighter #6AA300 so they still pop.
