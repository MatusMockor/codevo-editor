## 2. Decisions

D1 Token layer — one role layer `--codevo-*`, values from the design, declared on `.app-shell` (dark) with the existing light selector list (`light|catppuccinLatte|oneLight` + `system` media). `--t3-*` is deleted. `--agent-*`, `--settings-*`, `--toast-*` become pure remaps of `--codevo-*` (no literal colours, radii or shadows outside `agentModeTokens.css`). Editor chrome (tabs, breadcrumbs, bottom panel, status bar, palettes, menus, trees) keeps reading `--color-*`; `:root` and light `--color-*` are re-valued to the Airy neutrals so all chrome moves without rewriting 7 000 lines: `--color-app/sidebar = canvas`, `--color-panel/panel-deep/status/tabs = panel`, `--color-surface/modal/tab-active = raised`, `--color-control = well`, `--color-hover/hover-strong/active = hover/active`, `--color-accent = primary`, text roles, radii `--radius-sm/md/lg = 8/10/12` + new `--radius-xl: 14px`, `--shadow-pop = --codevo-shadow-float`, `--focus-ring = --codevo-focus-ring`. Other eight themes keep their palettes; `--codevo-*` on `.app-shell` is defined as `var(--color-*)` remaps so they resolve by construction, and only `:root`/light carry the Airy literals. Ladder (dark/light): canvas `#0c0d10/#fbfcfd` (rail, thread canvas, Monaco), panel `#13151a/#f0f2f5` (right panel, bottom panel, status bar, settings nav), raised `#1a1d23/#ffffff` (cards, composer, prompt, active tabs, menus, palettes, dialogs, toasts), well `#0f1014/#eaedf1` (inputs, kbd, pills), hover/active/selected, fg strong/body/muted/subtle/disabled, primary `#4fcdb3/#15907c` + `primary-fg` + `primary-soft`, ok/warn/danger + softs, `--codevo-ft-{ts,tsx,js,json,npm,md,css,sh,docker,git,env,lock}`, `--codevo-diff-add/del`, `--codevo-shadow-card` (`none` dark / soft light), `--codevo-shadow-float`, `--codevo-shadow-window`, `--codevo-separator-inset: 0 -1px 0 var(--codevo-well)`, `--codevo-focus-ring: 0 0 0 2px var(--codevo-canvas), 0 0 0 4px var(--codevo-primary)`, radii `--codevo-r-sm/md/lg/xl 8/10/12/14`, type scale `--codevo-fs-hero/title/heading/body/ui/meta/small/label 26/20/15/13.5/13/12/11/10`, `--codevo-sans: Inter, ui-sans-serif, system-ui, -apple-system, …`, `--codevo-mono`, `--codevo-icon: 16px`, `--codevo-icon-stroke: 1.75`. D2 Border policy as a contract test — `src/components/cssBorderContract.test.ts` parses every `src/**/*.css` (comments stripped, rule bodies with their selector) and asserts: (a) every `border`, `border-{top,right,bottom,left,inline*,block*}`, `border-color`, `border-width`, `border-style` declaration has value `0`, `none` or `0 none` (`transparent` and `currentColor` are rejected because they keep the 1 px layout); (b) every `outline` declaration is `0`/`none` unless the rule's selector contains `:focus-visible`; (c) every `box-shadow` value is `none` or consists only of `var(--codevo-shadow-card|shadow-float|shadow-window|focus-ring|separator-inset)` / `var(--agent-focus-ring|shadow-raised)` / `var(--settings-…)`/`var(--toast-…)` tokens that themselves resolve to those (the test resolves one remap level); (d) `--codevo-separator-inset` may be consumed only by selectors in a fixed list (`.settings-row + .settings-row`, `.settings-provider + .settings-provider`); (e) a ratchet: `cssBorderAllowlist.ts` lists selectors in `App.css` for legacy panels not in this slice's scope (activity bar, sidebar header, debug/test/git side panels, Nette/Laravel panels, dirty-close/conflict/change-signature dialog internals). ## 6. Risks

- Monaco single mount: the expanded shell reuses the existing overlay; the new `data-editor="empty"` path must hide via CSS only. Test asserts the editor slot stays in the DOM.
- Clipping math in maximized state can leave a dead strip under the docked tree; covered by the layout contract test and QA step 5 at 1280 and 1024 px.
- Hotspot budgets: `App.tsx` has zero headroom, hence the report-context design; verify `AgentSurfacePanel.tsx`/`AgentWorkbenchScreen.tsx` with `npm run size:hotspots`.
- Border contract over `App.css` (164 declarations): the ratchet must be frozen at S0 with exact selectors; S4 must not "solve" red entries by moving them into the allowlist.
- Re-valuing `--color-*` affects every legacy panel (git, debug, tests) — they get the new tones but keep their (allowlisted) borders until the follow-up.
- `TREE_ROW_HEIGHT` 30→26 changes virtualisation math and the perf test fixtures; keep the constant single-sourced.
- Light contrast: `--codevo-fg-subtle #99a1ad` on white is below 4.5:1; use it only for placeholders/icons, never body text.
- `--toast-primary`/`--settings-primary` currently hard-code T3 blue; missing one remap leaves a blue control (token contract catches literals).
